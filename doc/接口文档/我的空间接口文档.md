# 副站我的空间接口文档

> **模块**：linlang-workspace-server
> **包路径**：`com.ai.linlang.workspace.controller.substation`
> **Controller**：`SpaceSubstationController`
> **基础路径**：`/app-api/substation`
> **作者**：LSH（2026-06-25）

---

## 一、模块说明

副站「我的空间」面向 **C 端客户端**，提供物料/作品的浏览、检索与 UGC 上行能力，是 [[myspace-design]] 设计方案的对外出口。底层统一落在 `dp_material` 单表，通过 `type × businessType` 两个维度承载全部业务作品。

- **作品模型**：`dp_material` 单表，`type`（0-素材 / 1-模板 / 2-AI生成）× `businessType`（0-图片 / 1-语音 / 2-视频 / 3-PPT）二维区分。
- **三类入口**：我的作品（仅 PPT / 全部业务）、团队空间作品（按 `spaceUid`）、收藏列表。
- **UGC 上行**：`publishWork` / `publishMaterial` 把个人作品/素材上行到公共模板库 / 公共素材库。
- **鉴权**：全部接口依赖登录态，服务端通过 `SecurityFrameworkUtils.getLoginUserId()` 取当前用户，**前端无需传 userId**。
- **团队上下文**：副站**不提供团队切换**，统一取主站最近一次切换的团队（`/current-team` 只读）；团队作品接口 `getTeamWorkList` 的 `spaceUid` 可选，不传时自动取最近团队，无任何团队时返回空页。

## 二、通用约定

### 2.1 请求外层结构（BaseRequest\<T\>）

所有接口请求体统一为 `BaseRequest<T>`，业务参数放在 `queryParameter` 中：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| basicInfo | BasicInfo | 是 | 基础公共参数 |
| i18n | I18nInfo | 是 | 国际化参数 |
| queryParameter | T | - | 业务请求参数（各接口不同，见下）|

**BasicInfo**

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| busId | Long | 是 | 商户ID |
| cid | Long | 是 | 用户ID |
| refer | String | 是 | 页面唯一标识 |
| source | Integer | 是 | 渠道来源：0-Web 1-Mobile 2-App 3-WeChat 4-Other |
| hcode | String | 是 | 租户标识 |
| version | String | 是 | 版本信息 |

**I18nInfo**

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| language | String | 是 | 语言代码：zh / en / ja / ko |
| timezone | String | 是 | 时区，格式 `+HHmm` / `-HHmm`（如 `+0800`）|

### 2.2 分页参数（PageParam）

列表类接口的 `queryParameter` 继承 `PageParam`，公共分页字段：

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|:----:|:----:|------|
| pageNo | Integer | 是 | 1 | 页码，从 1 开始 |
| pageSize | Integer | 是 | 10 | 每页条数，最大 100；传 `-1` 不分页 |

### 2.3 响应结构（CommonResult\<T\>）

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 错误码，`0` 表示成功 |
| msg | String | 提示信息，成功时为空串 |
| data | T | 返回数据 |

### 2.4 分页响应（PageResult\<T\>）

列表接口的 `data` 为 `PageResult<T>`：

| 字段 | 类型 | 说明 |
|------|------|------|
| total | Long | 总条数 |
| list | List\<T\> | 当前页数据 |

## 三、接口清单

| 接口 | 方法 | 路径 | 说明 |
|------|:----:|------|------|
| 获取副站当前团队空间 | GET | `/app-api/substation/current-team` | 取主站最近切换的团队（只读，首屏调用）|

### 4.2 获取文件夹信息

**`POST /app-api/substation/info`**

根据 `folderUid` / `spaceUid` 获取文件夹与物料的联合信息，支持自定义搜索条件与排序。

#### queryParameter — SubstationFolderReq（extends PageParam）

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| folderUid | String | 否 | 文件夹UID |
| spaceUid | String | 否 | 空间UID |
| type | Integer | 否 | 类型：`0`-素材 `1`-模板 |
| keywords | String | 否 | 关键词（模板/素材名称）|
| search | List\<SearchConditionReq\> | 否 | 搜索条件列表 |
| sort | List\<SortConditionReq\> | 否 | 排序条件列表 |
| pageNo | Integer | 是 | 页码，默认 1 |
| pageSize | Integer | 是 | 每页条数，默认 10，最大 100 |

**SearchConditionReq**

| 字段 | 类型 | 说明 |
|------|------|------|
| field | String | 搜索字段名 |
| value | String | 搜索值 |
| operator | String | 操作符（`like` / `equals` / `in` 等）|

**SortConditionReq**

| 字段 | 类型 | 说明 |
|------|------|------|
| key | String | 排序字段（`createdAt` / `updatedAt` / `size` / `name`）|
| order | String | 排序方式（`ASC` 升序 / `DESC` 降序）|

#### 请求示例

```json
{
  "basicInfo": { "busId": 123456, "cid": 100001, "refer": "substation-folder", "source": 2, "hcode": "linlang", "version": "0.0.1" },
  "i18n": { "language": "zh", "timezone": "+0800" },
  "queryParameter": {
    "folderUid": "fld_xxx",
    "spaceUid": "sp_xxx",
    "type": 1,
    "keywords": "汇报",

      { "field": "name", "value": "汇报", "operator": "like" }
    ],
    "sort": [
      { "key": "createdAt", "order": "DESC" }
    ],
    "pageNo": 1,
    "pageSize": 20
  }
}
```

```json

  "msg": "",
  "data": {
    "total": 2,
    "list": [
      {
        "sourceType": 2,
        "id": 300,
        "uid": "fld_xxx",
        "name": "我的PPT",
        "materialCount": 12,
        "type": 1,
        "isRoot": false,
        "createdAt": "2026-06-01 09:00:00",
        "updatedAt": "2026-06-28 16:30:00"
      },
      {
        "sourceType": 4,
        "materialId": 5001,
        "materialName": "年终汇报.pptx",
        "materialUrl": "https://oss.example.com/material/5001.json",
        "previewUrl": "https://oss.example.com/material/5001/cover.png",
        "filename": "年终汇报.pptx",
        "size": 2048576,
        "isCollect": true,
```

> `sourceType=2` 行为文件夹，`sourceType=4` 行为物料，字段按类型语义取值。完整字段见 [§五 - SubstationInfoRepsVO](#substationinforepsvo)。

### 4.8 获取副站当前团队空间

**`GET /app-api/substation/current-team`**

获取副站当前生效的团队空间。**副站不提供团队切换**，统一取主站最近一次切换的团队作为上下文（主站通过 `/app-api/team-space/switch` 写入）。

> 副站前端首屏调用本接口，确定当前所在团队（只读展示，无切换 UI）。

#### 请求

GET 请求，仅需登录态（无 `queryParameter`）。仍需带常规 `basicInfo` / `i18n` 外层。

```json
{
  "basicInfo": { "busId": 123456, "cid": 100001, "refer": "substation-current-team", "source": 2, "hcode": "linlang", "version": "0.0.1" },
  "i18n": { "language": "zh", "timezone": "+0800" }
}
```

#### 响应 — TeamSpaceRepsVO 或 null

用户有最近团队时返回团队详情（结构见 [团队空间接口文档 · TeamSpaceRepsVO](团队空间接口文档.md#teamspacerepsvo)）；无任何团队时返回 `null`。

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "id": 300,
    "uid": "sp_xxx",
    "name": "市场部设计组",
    "icon": "https://oss.example.com/team/icon_001.png",
    "description": "市场部日常设计协作",
    "creatorId": 100001,
    "memberCount": 5,
    "currentUserRole": "EDITOR",
    "permissions": ["VIEW", "EDIT"],
    "rootFolder": {
      "id": 9001,
      "uid": "fld_root_xxx",
      "name": "市场部设计组",
      "isRoot": true,
      "spaceId": 300
    },
    "createdAt": "2026-06-01 09:00:00",
    "updatedAt": "2026-06-28 16:30:00"
  }
}
```

> 无团队时：`{ "code": 0, "msg": "", "data": null }`，前端可引导用户去主站加入/创建团队。

#### 解析规则（服务端 `TeamSpaceService.getLastTeamSpaceUid`）

1. **Redis 记忆**（主站 `/switch` 写入）→ 校验空间仍有效 + 当前用户仍是成员 → 命中（滑动续期）。
2. **记忆失效 / 无记忆** → fallback 用户最近加入的有效团队（`joined_at` 倒序首条）→ 回填 Redis。
3. **无任何团队** → 返回 `null`。

> 失效场景（被移出 / 团队解散）由读取侧自动兜底，无需用户干预。

## 六、业务规则

- **鉴权**：全部接口需登录态，`userId` 由服务端从 Token 解析，前端**不要**在 `queryParameter` 传用户ID。
- **type 与 businessType 语义**：`type` 区分素材/模板/AI生成（数据形态维度），`businessType` 区分图片/语音/视频/PPT（业务内容维度），二者正交可任意组合过滤。
- **getMyWorkList vs getMyAllWorkList**：前者固定查 PPT；后者通用，不传 `businessType` 即查全部业务。团队入口 `getTeamWorkList` 必须传 `spaceUid`。
- **UGC 上行**：`publishWork` 针对作品（→公共模板库），`publishMaterial` 针对素材（→公共素材库，须 `type=0`）。二者 `queryParameter` 均无分页字段。
- **分页**：列表接口 `pageSize` 上限 100，传 `-1` 可不分页。
