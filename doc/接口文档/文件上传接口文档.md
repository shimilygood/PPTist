## 接口列表

### 1. 临时文件上传

**接口地址**: `POST /api/content/fileTempOss/upload`

**接口描述**: 上传临时文件到OSS（需要登录）

**请求类型**: `multipart/form-data`

**请求参数**:

| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| file | File | 是 | 上传的文件 |

**响应示例**:

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "id": 1,
    "filePath": "/temp/2024/01/01/file123.png",
    "name": "file123.png",
    "url": "https://example.com/temp/file123.png",
    "size": 123456
  }
}
```

**响应字段说明**:

| 字段 | 类型 | 描述 |
|------|------|------|
| id | Long | 文件ID |
| filePath | String | 文件路径 |
| name | String | 文件名称 |
| url | String | 文件访问URL |
| size | Long | 文件大小 |

---

### 2. 获取临时文件

**接口地址**: `POST /api/content/fileTempOss/getTempFile`

**接口描述**: 根据文件ID获取临时文件信息（需要登录）

**请求示例**:

```json
{
  "basicInfo": {
    "busId": 123456,
    "cid": 123456,
    "refer": "home",
    "source": 0,
    "hcode": "linlang",
    "version": "0.0.1"
  },
  "i18n": {
    "language": "zh",
    "timezone": "+0800"
  },
  "queryParameter": {
    "id": 1
  }
}
```

**queryParameter参数说明**:

| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| id | Long | 是 | 文件ID |

**响应示例**:

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "id": 1,
    "name": "file123.png",
    "url": "https://example.com/temp/file123.png",
    "size": 123456,
    "type": "image/png"
  }
}
```

**响应字段说明**:

| 字段 | 类型 | 描述 |
|------|------|------|
| id | Long | 文件ID |
| name | String | 文件名称 |
| url | String | 文件访问URL |
| size | Long | 文件大小 |
| type | String | 文件MIME类型 |
