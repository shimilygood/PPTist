基础路径：`/api/content/hot-topic`

## 通用说明

### 请求结构

所有接口请求体统一为 `BaseRequest<T>` 格式：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| basicInfo | BasicInfo | 是 | 基础信息 |
| i18n | I18nInfo | 是 | 国际化信息 |
| queryParameter | T | 否 | 业务参数（各接口不同） |

#### BasicInfo

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| busId | Long | 是 | 商户ID |
| cid | Long | 是 | 用户ID |
| refer | String | 是 | 页面唯一标识 |
| source | Integer | 是 | 页面渠道来源（0-Web, 1-Mobile, 2-App, 3-WeChat, 4-Other） |
| hcode | String | 是 | 租户标识 |
| version | String | 是 | 版本信息 |

#### I18nInfo

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| language | String | 是 | 语言代码（zh-中文, en-英文, ja-日文, ko-韩文） |
| timezone | String | 是 | 时区（格式: +HHmm 或 -HHmm） |

### 响应结构

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 错误码，0 表示成功 |
| msg | String | 错误提示信息 |
| data | T | 返回数据（各接口不同） |

## 1. 获得热门主题列表

**POST** `/api/content/hot-topic/list`

**鉴权：** 无需登录（@PermitAll）

**描述：** 根据类型获取热门主题列表。

### 请求参数（queryParameter）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | Integer | 否 | 类型，精确匹配（0-PPT） |

### 请求示例

```json
{
  "basicInfo": {
    "busId": 1001,
    "cid": 2001,
    "refer": "home",
    "source": 0,
    "hcode": "linlang",
    "version": "1.0.0"
  },
  "i18n": {
    "language": "zh",
    "timezone": "+0800"
  },
  "queryParameter": {
    "type": 0
  }
}
```

### 响应参数（data）

`HotTopicRespVO[]`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 编号 |
| title | String | 标题 |
| type | Integer | 类型（0-PPT） |
| createTime | String | 创建时间（yyyy-MM-dd HH:mm:ss） |

### 响应示例

```json
{
  "code": 0,
  "msg": "",
  "data": [
    {
      "id": 1,
      "title": "商务汇报",
      "type": 0,
      "createTime": "2025-01-15 10:30:00"
    },
    {
      "id": 2,
      "title": "教育培训",
      "type": 0,
      "createTime": "2025-01-16 14:20:00"
    }
  ]
}
```

## 数据模型

```
hot_topic (热门主题表)
  ├── id (主键)
  ├── type (类型, 0-PPT)
  ├── title (标题)
  ├── tenant_id (租户编号)
  ├── create_time (创建时间)
  ├── update_time (更新时间)
  ├── creator (创建人)
  ├── updater (更新人)
  └── deleted (是否删除)
```
