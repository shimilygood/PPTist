## 接口列表

### 1. 获取用户个人空间

**接口地址**: `POST /app-api/space/getUserSpace`

**接口描述**: 获取当前用户的个人空间（需要登录）

**请求示例**:

```json
{
  "basicInfo": {
    "busId": 123456,
    "cid": 123456,
    "refer": "home",
    "source": 0,
    "hcode": "linlang",
    "version": "0.0.1"
  },
  "i18n": {
    "language": "zh",
    "timezone": "+0800"
  },
  "queryParameter": {
    
  }
}
```

**响应示例**:

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "id": 1,
    "uid": "space_abc123",
    "name": "我的空间",
    "description": "个人创作空间",
    "rootFolder": {
      "id": 1,
      "uid": "folder_root",
      "name": "根目录"
    }
  }
}
```

**响应字段说明**:

| 字段 | 类型 | 描述 |
|------|------|------|
| id | Long | 空间ID |
| uid | String | 空间唯一标识 |
| name | String | 空间名称 |
| description | String | 空间描述 |
| rootFolder | Object | Root文件夹VO |

---

### 2. 创建个人空间

**接口地址**: `POST /app-api/space/create`

**接口描述**: 创建新的个人空间（需要登录）

**请求示例**:

```json
{
  "basicInfo": {
    "busId": 123456,
    "cid": 123456,
    "refer": "home",
    "source": 0,
    "hcode": "linlang",
    "version": "0.0.1"
  },
  "i18n": {
    "language": "zh",
    "timezone": "+0800"
  },
  "queryParameter": {
    "name": "我的新空间",
    "thumbnail": "https://example.com/thumb.png",
    "description": "这是一个新空间"
  }
}
```

**queryParameter参数说明**:

| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| name | String | 是 | 空间名称（1-25字符） |
| thumbnail | String | 否 | 缩略图（最大500字符） |
| description | String | 否 | 空间描述（最大100字符） |

**响应示例**:

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "id": 2,
    "uid": "space_xyz789",
    "name": "我的新空间",
    "description": "这是一个新空间"
  }
}
```

**响应字段说明**:

| 字段 | 类型 | 描述 |
|------|------|------|
| id | Long | 空间ID |
| uid | String | 空间唯一标识 |
| name | String | 空间名称 |
| description | String | 空间描述 |
