# 编辑器-素材接口文档

## 接口列表

### 1. 编辑器-素材分组列表

**接口地址**: `POST /api/design/material/getMaterial`

**接口描述**: 按分组获取素材列表，排除一级分组(parentId=0)，每个分组最多展示6个素材。返回素材包含图层信息，materialData有值时取其cover，否则取thumbnailUrl。

**请求示例**:

```json
{
  "basicInfo": {
    "busId": 123456,
    "cid": 123456,
    "refer": "home",
    "source": 0,
    "hcode": "linlang",
    "version": "0.0.1"
  },
  "i18n": {
    "language": "zh",
    "timezone": "+0800"
  },
  "queryParameter": {}
}
```

**响应示例**:

```json
{
  "code": 0,
  "msg": "成功",
  "data": [
    {
      "id": 1,
      "groupName": "分组名称",
      "list": [
        {
          "id": 1,
          "name": "素材名称",
          "data": [
            {
              "id": 1,
              "name": "图层名称",
              "cover": "https://example.com/cover.png",
              "json": "{}",
              "style": 1,
              "layerType": 1,
              "sort": 1
            }
          ]
        }
      ]
    }
  ]
}
```

**响应字段说明**:

| 字段 | 类型 | 描述 |
|------|------|------|
| id | Long | 分组ID |
| groupName | String | 分组名称 |
| list | List | 素材列表（最多6个） |
| ├─ id | Long | 素材ID |
| ├─ name | String | 素材名称 |
| ├─ data | List | 图层数据列表（materialData有值时取其cover，否则取thumbnailUrl） |
| &emsp;&nbsp;├─ id | Long | 图层ID |
| &emsp;&nbsp;├─ name | String | 图层名称 |
| &emsp;&nbsp;├─ cover | String | 封面 |
| &emsp;&nbsp;├─ json | String | 图层数据(JSON) |
| &emsp;&nbsp;├─ style | Integer | 风格 |
| &emsp;&nbsp;├─ layerType | Integer | 图层类型（0:模板 1:素材） |
| &emsp;&nbsp;├─ sort | Integer | 排序 |

---

### 2. 编辑器-素材类型树列表

**接口地址**: `POST /api/design/material/getMaterialOther`

**接口描述**: 按类型-分组-素材三层结构展示。仅返回分类名称为'图片'、'背景'、'字体'的数据。每个分组最多展示6个素材，materialData有值时取其cover，否则取thumbnailUrl。

**请求示例**:

```json
{
  "basicInfo": {
    "busId": 123456,
    "cid": 123456,
    "refer": "home",
    "source": 0,
    "hcode": "linlang",
    "version": "0.0.1"
  },
  "i18n": {
    "language": "zh",
    "timezone": "+0800"
  },
  "queryParameter": {}
}
```

**响应示例**:

```json
{
  "code": 0,
  "msg": "成功",
  "data": [
    {
      "typeId": 1,
      "typeName": "图片",
      "groups": [
        {
          "groupId": 1,
          "groupName": "风景",
          "materials": [
            {
              "id": 1,
              "name": "素材名称",
              "data": [
                {
                  "id": 1,
                  "name": "图层名称",
                  "cover": "https://example.com/cover.png",
                  "json": "{}",
                  "style": 1,
                  "layerType": 1,
                  "sort": 1
                }
              ]
            }
          ]
        }
      ]
    }
  ]
}
```

**响应字段说明**:

| 字段 | 类型 | 描述 |
|------|------|------|
| typeId | Long | 类型ID |
| typeName | String | 类型名称（仅返回：图片、背景、字体） |
| groups | List | 分组列表 |
| ├─ groupId | Long | 分组ID |
| ├─ groupName | String | 分组名称 |
| ├─ materials | List | 素材列表（最多6个） |
| &emsp;&nbsp;├─ id | Long | 素材ID |
| &emsp;&nbsp;├─ name | String | 素材名称 |
| &emsp;&nbsp;├─ data | List | 图层数据列表 |
| &emsp;&nbsp;&emsp;&nbsp;├─ cover | String | 封面（materialData有值时取其cover，否则取thumbnailUrl） |

### 3. 编辑器-素材分页搜索

**接口地址**: `POST /api/design/material/search`

**接口描述**: 分页搜索素材列表，支持关键词、分组ID、类型ID筛选。返回素材基本信息及图层信息，materialData有值时取其cover，否则取thumbnailUrl。

**请求示例**:

```json
{
  "basicInfo": {
    "busId": 123456,
    "cid": 123456,
    "refer": "home",
    "source": 0,
    "hcode": "linlang",
    "version": "0.0.1"
  },
  "i18n": {
    "language": "zh",
    "timezone": "+0800"
  },
  "queryParameter": {
    "pageNo": 1,
    "pageSize": 10,
    "keywords": "搜索关键词",
    "groupId": 1,
    "typeId": 1
  }
}
```

**queryParameter参数说明**:

| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| pageNo | Integer | 是 | 页码 |
| pageSize | Integer | 是 | 每页数量 |
| keywords | String | 否 | 搜索关键词 |
| groupId | Long | 否 | 分组ID |
| typeId | Long | 否 | 类型ID |

**响应示例**:

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "records": [
      {
        "id": 1,
        "name": "素材名称",
        "thumbnailUrl": "https://example.com/thumb.png",
        "width": 1920,
        "height": 1080,
        "fileSize": 123456,
        "price": 0.00,
        "data": [
          {
            "id": 1,
            "name": "图层名称",
            "cover": "https://example.com/cover.png",
            "json": "{}",
            "style": 1,
            "layerType": 1,
            "sort": 1
          }
        ]
      }
    ],
    "total": 100,
    "size": 10,
    "current": 1,
    "pages": 10
  }
}
```

**响应字段说明**:

| 字段 | 类型 | 描述 |
|------|------|------|
| id | Long | 素材ID |
| name | String | 素材名称 |
| thumbnailUrl | String | 缩略图URL |
| width | Integer | 宽度 |
| height | Integer | 高度 |
| fileSize | Long | 文件大小 |
| price | BigDecimal | 价格 |
| data | List | 图层数据列表 |
| ├─ cover | String | 封面（materialData有值时取其cover，否则取thumbnailUrl） |

### 4. 编辑器-发布或保存素材

**接口地址**: `POST /api/design/material/action`

**接口描述**: 发布或保存素材（需要登录）。将图层信息保存到material_layer_info表，图层数据上传OSS后存储URL。

**请求示例**:

```json
{
  "basicInfo": {
    "busId": 123456,
    "cid": 123456,
    "refer": "home",
    "source": 0,
    "hcode": "linlang",
    "version": "0.0.1"
  },
  "i18n": {
    "language": "zh",
    "timezone": "+0800"
  },
  "queryParameter": {
    "id": 1,
    "name": "素材名称",
    "action": 1,
    "data": [
      {
        "id": 1,
        "name": "图层名称",
        "cover": "https://example.com/cover.png",
        "json": "{}",
        "style": 1,
        "layerType": 1,
        "sort": 1
      }
    ]
  }
}
```

**queryParameter参数说明**:

| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| id | Long | 否 | 素材ID（修改时必填，新增时为空） |
| name | String | 是 | 素材名称 |
| action | Long | 是 | 操作类型：0-保存草稿，1-发布 |
| roleAction | Boolean | 是 | 设计师专用：false-编辑，true-新增 |
| data | List | 是 | 图层信息列表 |
| ├─ id | Long | 否 | 图层ID（修改时必填） |
| ├─ name | String | 是 | 图层名称 |
| ├─ cover | String | 否 | 封面图URL |
| ├─ json | String | 是 | 图层数据(JSON字符串) |
| ├─ style | Integer | 否 | 风格 |
| ├─ layerType | Integer | 否 | 图层类型（0:模板 1:素材） |
| ├─ sort | Integer | 否 | 排序 |

**响应示例**:

```json
{
  "code": 0,
  "msg": "成功",
  "data": true
}
```
